# SmsForwarder 官方 APK 下载指引

SmsForwarder（短信转发器）是开源的 Android 应用，可把微信/短信等通知转发到自定义 HTTP 接口。本增量功能用它把**微信收款通知**推送到 sea1 激活服务器。

> 本文件为「备查 / 给他人用」的下载与权限指引。你本地若已装好，可跳过安装步骤。

---

## 1. 官方下载地址（GitHub Releases）

项目主页与发布页：

- GitHub 仓库：`pppscn/SmsForwarder`
- Releases（含官方编译好的 APK）：
  https://github.com/pppscn/SmsForwarder/releases

下载建议：
- 在 Releases 列表里选**最新稳定版**（如 `v_3.x.x`）。
- 下载 **`SmsForwarder_xxx_arm64_v8a.apk`**（主流手机）或对应架构的 APK；`universal` 版本兼容性最好但体积大。
- 校验文件大小与发布页一致，避免第三方篡改。

> 说明：本项目**不内置、不分发** APK 二进制；请从上述官方 Release 获取，确保安全。

---

## 2. 安装步骤

1. Android 手机：设置 → 关于手机 → 连续点「版本号」开启**开发者选项** → 打开「未知来源应用安装」允许浏览器/文件管理器安装。
2. 用手机浏览器打开上面的 Releases 链接，下载 APK。
3. 点击 APK 完成安装。
4. 首次打开，按引导授予所需权限（见下）。

---

## 3. 必要权限（务必授予，否则收不到通知）

| 权限 | 作用 | 开启路径（示意） |
|------|------|------------------|
| **通知读取 / 通知使用权（Notification Access）** | 读取微信收款等通知内容（核心） | 系统设置 → 通知 → 高级 → 通知读取/通知使用权 → 开启 SmsForwarder |
| **通知栏监听 / 通知监听** | 部分 ROM 需额外在「通知管理」里允许 SmsForwarder 监听 | 系统设置 → 应用 → SmsForwarder → 通知 → 允许 |
| **无障碍服务（Accessibility）** | 某些机型/版本用于可靠抓取通知文本 | 系统设置 → 无障碍 → 已下载应用 → SmsForwarder → 开启 |
| **后台运行 / 自启动 / 电池优化** | 防止被系统杀后台导致转发中断 | 系统设置 → 电池 → 应用启动管理 → 允许自启动/关联启动；电池优化 → 不优化 SmsForwarder |
| **网络（Wi-Fi/移动数据）** | 向服务器 POST webhook | 默认即有；注意在同一局域网或可达地址 |

> 微信收款通知属于「通知」，SmsForwarder 通过**通知监听**获取，无需 root。不同手机厂商路径略有差异，但都围绕「通知使用权 / 无障碍」两类。

---

## 4. 与微信的关系

- SmsForwarder **不需要**微信账号/登录，只读取微信产生的「系统通知」文本。
- 你付款时微信会弹出「微信支付 - 收款通知」类通知，SmsForwarder 捕获其文本 → 转发到激活服务器 webhook。
- 不需要在微信里做任何特殊设置，只要微信的收款通知能正常弹出即可。

---

## 5. 隐私与安全

- 转发内容仅含「通知文本 + 应用包名 + 时间戳」等，不含微信聊天记录。
- webhook 走 `?secret=` 验签（fail-closed），且同局域网/可信网络访问最佳。
- 官方 Release 经社区校验；如用于生产，建议固定版本、校验下载完整性，并保持 `WEBHOOK_SECRET` 不泄露。
