## 一、产品目标
为降低新用户开通会员的操作门槛与认知负担，将「一句话猜套餐+渠道」改为「菜单选时长」状态机，将「金额偏移匹配」改为更稳健的「唯一备注（sea+时间戳）匹配」；同时在试用期到期后**首次打印完成**这一关键触点主动提醒续费，并在菜单中补齐会员指令、统一友好文案，从而提升激活转化率与整体自助体验。

---

## 二、用户故事
1. **新用户开通会员全流程**：作为新用户，我希望发送「开通会员」后看到清晰的长时长菜单（月/季/年/永久及价格），只需回复数字即可下单，而不必在一句话里说清套餐和渠道，从而轻松完成开通。
2. **老用户付完款如何匹配**：作为已完成支付或系统本身，我希望微信/支付宝收款备注里带上唯一订单号（sea+时间戳），系统凭备注直接命中对应订单并自动发码，而不依赖易错的金额匹配，从而减少「已付款却没收到码」的情况。
3. **试用期到期首印提醒**：作为试用期已到期的用户，我希望在试用期结束后**第一次打印完成**时收到温柔提醒（告知体验期已结束、建议开通会员以免影响下次使用），从而在真正需要时被恰当触达，而非被频繁私聊打扰。
4. **管理员/指令可见性**：作为普通用户或管理员，我希望在「智能打印」与「管理命令」菜单中看到会员相关指令（开通会员、我的会员、付款记录、推送查询等），从而自助发现并使用这些功能，减少重复询问。

## 四、交互 / 文案设计稿

### 4.1 开通会员菜单流程
**用户发送**（任一触发词）：`开通会员` / `会员` / `购买` / `vip` / `buy` / `pay` / `付费` / `充值` / `续费` / `激活`

**→ bot 回复菜单：**
```
【开通会员】
请选择要开通的会员时长：
1. 月卡 5元
2. 季卡 12元
3. 年卡 48元
4. 永久会员 128元

回复对应数字即可下单（如需退出请回复「取消」）。
```

**用户回复可选形式**：纯数字 `1`/`2`/`3`/`4`；带标点 `1.`；或 `取消`。

**→ 用户回 `3`（年卡 48元）→ bot 建单并回执：**
```
✅ 订单已创建（年卡 48元）
订单号：sea20260729123059
金额：48 元
收款方式：微信（默认，见待确认）
请使用微信付款，并在付款备注中粘贴订单号：
sea20260729123059
（长按复制订单号）

付款成功后系统将自动核验并发放会员，无需其他操作。
```

**→ 用户付款，备注填 `sea20260729123059` → webhook 备注匹配命中 → markPaid → bot 自动发 license：**
```
🎉 支付成功，会员已开通！
会员类型：年卡
有效期至：2027-07-29
License 已绑定本机，感谢支持！
```

**（可选兜底）** 若用户主动发「已支付 sea20260729123059」→ 走手动 confirm → 轮询监控器核验 → 发码（保留旧路径）。

**错误处理：**
- 用户回 `5` / `abc` → bot：
```
请回复 1-4 之间的数字选择时长：
1. 月卡 5元  2. 季卡 12元  3. 年卡 48元  4. 永久会员 128元
```
- 用户回 `取消` → bot：
```
已取消开通，可随时发送「开通会员」重新选择。
```

### 4.2 打印完成提醒文案（试用期到期首印）
**触发条件**：用户试用期已到期，且本次是该账号到期后**首次**打印完成（去重标记控制，仅一次）。

**· bot 在打印完成回执后追加/或单独发送：**
```
📄 打印已完成。
温馨提示：您的体验期已结束。为不影响下次使用，请及时开通会员版本。
指令：开通会员
（回复「开通会员」即可选择会员时长）
```
> 说明：该提醒仅在到期后首次打印触发一次，后续打印不再重复；未到期不打扰；不影响原有打印完成回执。

### 4.3 补充后的菜单完整文案
在现有「[智能打印]」与「[管理命令]」基础上新增「[会员服务]」分组（或并入管理命令），示例如下：
```
【智能打印】
- 打印 <文件/链接>

【会员服务】

- 付款记录：查看历史订单与支付状态
- 推送查询：查询激活/发码推送状态

【管理命令】
- 试用 N：设置体验期时长
- 状态
- 帮助
（原有管理命令保留）
```
