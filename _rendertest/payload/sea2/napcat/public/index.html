⚙️ 原生管理台

打开 NapCat 原生管理台（自动登录缓存 / 账密登录 / 完整配置）。扫码登录负责首次连接，更多账号与配置项请进入原生界面。经中间页代理打开，后端自动注入登录凭据，免手动登录。

sea2 二进制 NapCat 为主通道，sea1 为备用框架；切换由 watchdog 执行（docker napcat 常驻，sea2 副通道依赖）
frp 隧道配置示例（type=tcp 透传 13011，HTTP+WS 全透传，最稳） 
[sea2-13011]
type = tcp
local_ip = 127.0.0.1
local_port = 13011
remote_port = 13011
仅需暴露 13011 单端口：静态页、/api/*、WebUI 代理（/webui/、/napcat-webui/）与 WS 升级全部经此端口。
